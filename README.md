## 主题

| 主题 | 风格 |
| --- | --- |
| 晴岚 · 薄荷 | 薄荷青与雾白渐变，轻描边、低灰阶的透亮界面 |
| 晴岚 · 晴空 | 天青蓝与蓝紫点缀，清爽干净，不偏青绿 |

## 在线安装

在 EchoMusic「插件管理 → 在线插件」添加插件源：

```text
https://github.com/zhonglixun/echomusic-clear-glass-theme
```

刷新插件列表后安装「晴岚 · 清透主题」，然后重新启动 EchoMusic。

## 启用主题

1. 在「插件管理」中启用「晴岚 · 清透主题」。
2. 打开左下角 T 恤图标 →「主题中心」→「主题」。
3. 选择「晴岚 · 薄荷」或「晴岚 · 晴空」。
4. 进入「外观调整」可继续调整面板雾白度、氛围光感、阴影和分区图标点缀。

> 「个性主题」是进入主题中心后的页面标题，不是插件启用入口。

## 功能

- 两套完整浅色／深色主题，不修改 EchoMusic 本体。
- 背景采用多色柔和渐变与环境光晕，避免大面积中性灰。
- 侧栏、内容区、详情页、评论、播放栏、设置和浮层使用统一透光材质。
- 图标点缀提供总开关及侧栏、快捷卡、标题栏、播放栏、内容区五个分区开关。
- 快捷卡按稳定功能 key 固定配色，拖动排序后颜色不变。
- 收藏红心、星标、危险操作保留语义色。
- 播放页歌词工具按钮沿用宿主原生按钮状态，仅调整圆形外观。

## 兼容性

- EchoMusic `>=2.3.2-beta.7`
- Manifest capability：`theme`
- 深浅模式由 EchoMusic 设置管理

## 视觉方向

- 浅色青白渐变贯穿侧栏、主内容和播放栏，不使用大面积灰底。
- 面板用低透明度雾白玻璃、细青灰描边和极轻阴影分层。
- 选中、悬停和标签使用薄荷青，而不是灰蓝色块。
- 深色变体也保持青绿冷调，不用中性灰铺满界面。

## 使用

1. 把 `clear-glass-theme` 整个文件夹放进 EchoMusic 的插件目录。
2. 在「插件管理」中启用「晴岚」——这一步只是加载主题。
3. **真正启用入口：左下角 T 恤图标 →「主题中心」→「主题」→ 直接从两张卡中选择：**
   - **晴岚 · 薄荷**：清爽薄荷绿
   - **晴岚 · 晴空**：天青蓝，不再偏绿
4. 在「外观调整 / 专属设置」里调节当前主题的面板雾白度、氛围光和阴影。
